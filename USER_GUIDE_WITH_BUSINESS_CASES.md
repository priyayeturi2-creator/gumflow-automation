## 📊 Overview

**GumFlow Automation Platform** is an AI-powered content automation solution that transforms founder interviews and company information into professional business documents and reports. The platform leverages advanced AI through Gumloop integration to generate multiple versions of content, enabling teams to select, approve, and refine business materials efficiently.

### Core Value Proposition
- **Time Savings**: Reduce content creation time from hours to minutes
- **Consistency**: Maintain brand voice and professional standards
- **Scalability**: Generate multiple content versions simultaneously
- **Quality Control**: Review, approve, and iterate on AI-generated content
- **Professional Output**: Download polished reports and documentation

## 📖 Step-by-Step User Guide

### Phase 1: Account Setup & Access

#### Step 1: Create Account
1. Click **"Register"** on the home page
2. Fill in required information:
   - Full Name
   - Email Address
   - Secure Password
3. Click **"Create Account"**
4. Verify email if required

#### Step 2: Login
1. Enter registered email and password
2. Click **"Login"**
3. Access main dashboard

### Phase 2: Creating Your First Automation Flow

#### Step 3: Start New Flow
1. Click **"Start New Gumflow Automation"** on the dashboard
2. Fill in the automation form:

**Required Fields**:
- **Founder Name**: Name of the person being interviewed
- **Company Name**: Name of your company/organization
- **Interview Transcript**: The raw interview content or notes
- **Tone**: Select appropriate tone for your content:
  - Professional (formal business communications)
  - Casual (informal, friendly approach)
  - Friendly (warm, approachable tone)
  - Technical (detailed, analytical approach)
  - Enthusiastic (energetic, positive tone)

#### Step 4: Submit & Monitor
1. Click **"Create Automation Flow"**
2. Monitor real-time status updates:
   - **RUNNING**: AI is processing your content
   - **COMPLETED**: Processing finished successfully
   - **FAILED**: Error occurred (see troubleshooting)

#### Step 5: Refresh Status
- Click the refresh icon to check latest processing status
- Status updates automatically every few seconds

### Phase 3: Managing Workbooks & Versions

#### Step 6: Access Workbooks
1. Once processing is complete, workbooks appear below the status section
2. Click on workbook accordions to expand and view contents

#### Step 7: Review Generated Versions
1. **Expand Workbook**: Click on any workbook to see available versions
2. **View Content**: Each version shows:
   - Generated content preview
   - Version ID and creation timestamp
   - Current selection status

#### Step 8: Select Preferred Version
1. **Choose Version**: Use radio buttons to select your preferred version
2. **Preview Content**: Review the generated content for quality and accuracy
3. **Multiple Selections**: Select different versions for different workbooks

#### Step 9: Version Management Actions

**Regenerate New Version**:
1. Click **"Regenerate"** button for any workbook
2. AI creates a new version with different approach
3. New version appears in the version list

**Approve Selected Version**:
1. Select your preferred version using radio button
2. Click **"Approve"** to mark as final
3. Approved versions are highlighted with green checkmark

### Phase 4: Generate & Download Reports

#### Step 10: Download Combined Report
1. After selecting and approving versions
2. Click **"Download Report"** button (only available if flow status is not FAILED)
3. System generates combined PDF report with all selected versions
4. Download begins automatically

### Phase 5: Flow Management

#### Step 11: View All Flows
1. Click **"Back to Flow List"** to see all your automation flows
2. View flow history with:
   - Company names
   - Creation dates
   - Current status
   - Run IDs for tracking

#### Step 12: Resume Previous Flows
1. Click on any flow from the list
2. Resume where you left off
3. Continue with version selection and approval

## 🛠️ Troubleshooting

### Common Issues & Solutions

#### Flow Status: FAILED
**Problem**: Automation flow fails during processing
**Solutions**:
1. Check internet connection
2. Verify all required fields are filled
3. Ensure transcript is properly formatted
4. Try regenerating the flow
5. Contact support if issue persists

#### No Workbooks Appearing
**Problem**: No workbooks show after flow completion
**Solutions**:
1. Refresh the page
2. Check flow status (must be COMPLETED)
3. Wait a few moments for processing
4. Click refresh status button

#### Download Not Working
**Problem**: Download Report button not functioning
**Solutions**:
1. Ensure flow status is not FAILED
2. Select at least one version in each workbook
3. Check browser download settings
4. Try different browser

#### Slow Loading
**Problem**: Application loads slowly or times out
**Solutions**:
1. Check internet connection speed
2. Clear browser cache
3. Try incognito/private browsing mode
4. Contact IT support for network issues

#### Login Issues
**Problem**: Cannot access account
**Solutions**:
1. Verify email and password
2. Check for typos in credentials
3. Use password reset if available
4. Clear browser cookies and try again
